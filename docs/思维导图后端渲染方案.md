# 思维导图后端渲染方案

## 概述

本方案实现了**100% 后端渲染**的思维导图生成功能，前端（Miniblink）只需显示静态图片，无需任何 JavaScript 渲染能力。

## 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 思维导图库 | **Markmap** | 专业的 Markdown 思维导图库 |
| HTML 生成 | **markmap-cli** | Markmap 官方命令行工具 |
| 截图引擎 | **Playwright** | 无头浏览器截图 |
| 后端框架 | **FastAPI** | Python 异步 Web 框架 |

## 工作流程

### 1. 用户请求生成思维导图
```
POST /mindmap/{doc_id}
```

### 2. 后端 LLM 生成 Markdown 内容
```markdown
# 主题
## 分支1
### 子节点1
### 子节点2
## 分支2
### 子节点3
```

### 3. Markmap CLI 生成 HTML
```bash
markmap input.md -o output.html
```
生成包含完整 Markmap 渲染代码的 HTML 文件。

### 4. Playwright 截图
```python
# 在独立进程中运行（避免 asyncio 冲突）
subprocess.run([
    sys.executable,
    "screenshot_worker.py",
    html_path,
    output_path,
    width,
    height
])
```

### 5. 返回图片 URL
```json
{
  "mindmap": "# 主题\n## 分支1...",
  "image_url": "/static/mindmaps/mindmap_xxx.png",
  "format": "png"
}
```

### 6. 前端显示图片
```html
<img src="/static/mindmaps/mindmap_xxx.png" />
```

### screenshot_worker.py（独立进程）

```python
def take_screenshot(html_path, output_path, width, height):
    from playwright.sync_api import sync_playwright
    
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page(viewport={'width': width, 'height': height})
        page.goto(f"file://{html_path}")
        page.wait_for_load_state('networkidle')
        time.sleep(1)  # 等待 Markmap 渲染
        page.screenshot(path=output_path)
        browser.close()
```

## 关键技术点

### 1. 为什么使用独立进程截图？

**问题**：Playwright 在 FastAPI 的 asyncio 事件循环中运行时，会在 Windows 上出现 `NotImplementedError`。

**解决方案**：使用 `subprocess` 调用独立的 Python 脚本进行截图，完全隔离事件循环。

```python
# 主进程（FastAPI）
subprocess.run([sys.executable, "screenshot_worker.py", ...])

# 子进程（独立事件循环）
with sync_playwright() as p:
    ...
```

### 2. 为什么选择 Markmap？

| 特性 | Markmap | 自定义 HTML/CSS | PIL 绘图 |
|------|---------|----------------|----------|
| 专业度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| 自动布局 | ✅ | ❌ | ❌ |
| 贝塞尔曲线 | ✅ | 需手动实现 | 需手动实现 |
| 彩色分支 | ✅ | 需手动实现 | 需手动实现 |
| 开发效率 | ⭐⭐⭐⭐⭐ | ⭐⭐ | ⭐ |

### 3. 前端兼容性

**前端只需要：**
- ✅ 显示 `<img>` 标签
- ✅ 发送 HTTP 请求

**前端不需要：**
- ❌ ES6 支持
- ❌ Markmap 库
- ❌ SVG 渲染
- ❌ 任何 JavaScript 渲染能力

**完美兼容 Miniblink 等轻量级浏览器内核。**
